# KhinsaOS — build plan

**Ship date:** 15 Sep 2026, 00:00 PKT
**Stack:** Vite + React + TS + Tailwind v4 + Framer Motion. No backend. Deploys as static files.

---

## The concept

She opens a link. It boots like a machine — POST lines, a progress bar, `Welcome back, Khinsa`.
Then a desktop with icons. Every icon is a small self-contained experience. Some are jokes.
One of them isn't.

**Tone:** roast-first, Hinglish — same voice as `khinsa-troll`, deliberately *not* the same look.
Sincerity is *earned*, not sprayed everywhere. Exactly one place drops the act.

**Look:** warm paper / vintage Mac. Cream ground `#f4efe4`, warm near-black ink `#1a1714`, 1px
hairlines with hard offset shadows (no blur), pinstriped title bars to signal window focus, menu bar
at the top, icons down the right edge. Accents: warm red `#c8452d`, ink blue `#3b5b7a`. Silkscreen
for chrome, Newsreader for reading, JetBrains Mono for the terminal. Photos read far better framed on
cream than glowing on black.

## What I need from you (start today)

### Photos — `content/photos/`
15–30 images. Name them anything. For each one I need **one line of caption**, in your voice, in the
register you'd actually text her. Not "a lovely memory :)". More like "you look deranged here and I
kept it on purpose."

### WhatsApp export — `content/raw/`
On her chat → ⋮ → More → Export chat → **Without media**. Drop `_chat.txt` in `content/raw/`.
I parse it **locally on your machine only**. Nothing uploads, nothing leaves the folder, and the raw
file never gets deployed — only the computed numbers do.

That gives us: total messages, who texts more, longest streak, latest-ever message, most-used word,
most-used emoji, first message ever sent, average reply time (and who makes who wait).

### Music — `public/music/` ✔ done
**Tape name: “If i miss Askari”** — lives in `CONFIG.tapeName` (`src/content/config.ts`), not in
`music.ts`, because that file is regenerated by the script.

Five tracks in, retagged and renamed. Run `npm run tape` after adding or removing any file.

**Still owed: the five `note` lines** in `src/content/music.ts` — one line each on why the song is
on the tape. That field is the whole reason the Music window exists. They are empty strings right

To reorder the tape, renumber the filenames and re-run the script.

### Voice notes / video — `content/media/`
Anything short. Yours, or ones you've collected. These get hidden, not displayed.

### Rishta Finder — `src/content/rishta.ts` + `public/faces/`
Built. The flow is: criteria → search → 10 candidates → the note → his card → Instagram.

**Photos: done.** All eleven are in and wired up.

Originals live in `assets-src/faces/` — deliberately **outside** `public/`, because Vite copies
`public/` into the build verbatim and the originals are 25 MB. `npm run faces` crops them square,
scales to 512x512, strips EXIF, and writes the web copies into `public/faces/`. **24.7 MB → 0.2 MB.**

To replace a photo: drop the new file in `assets-src/faces/<name>.jpg`, run `npm run faces`.
Crops are centred squares; `scripts/faces.mjs` has a `CROP` map for the exceptions
(`hassan.jpg` is framed to cut the caption off the bottom).

The generation prompts are in `assets-src/faces/PROMPTS.md` — moved out of `public/` so they
aren't readable at `/faces/PROMPTS.md` on the live site.

Any photo that goes missing still falls back to the drawn ink portrait. `/#portraits` shows a
contact sheet of those (dev only, stripped from the production build).

Also check `LAST_RESORT`: age is set to 20. I guessed **funny / acha humor / lamba** — swap in the 2–3 you
actually have — honest is funnier than generous.

## Notes

- **Weather widget** calls `api.open-meteo.com` at runtime. Keyless, CORS-open, no account, and it
  sends nothing but the coordinates in `CONFIG.place` — currently Lahore. Change the city there if
  she isn't in Lahore. If the API is unreachable the widget says so rather than spinning.
- **Desk layout** is a wrap flow, not fixed coordinates, so widgets never collide as the window
  narrows. Each one is draggable; positions aren't saved between visits.
