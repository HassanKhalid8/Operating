# Face prompts

I can't generate images — there's no image tool in my setup. These are written so you can paste
them into whatever you use (ChatGPT, Gemini, Midjourney, Grok) and get a set that looks like it
belongs together.

**Save each as the filename in its heading, into `assets-src/faces/`** (not this folder), then run
`npm run faces` to generate the web copies. Any file you skip falls back to the drawn ink portrait
automatically.

Any size — the script crops to square and scales to 512×512. The app renders them in warm greyscale,
so don't worry about colour.

---

## Paste this at the end of every prompt

> Head-and-shoulders portrait, facing the camera, plain flat light-grey studio backdrop, soft even
> lighting, sharp focus, passport-photo framing, no text, no watermark, no props. Fictional person,
> not a real or recognisable individual.
